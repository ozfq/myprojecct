مشروع «اربح مع أحمد عدنان الكعبور
=================================

هذه النسخة مبنية على فكرة المشروع الظاهرة في الفيديو المرفوع:
- صفحة سحب عربية RTL.
- عداد تنازلي.
- نموذج إدخال الاسم الأول واسم العائلة والبريد ورقم الجوال.
- حفظ البيانات في MySQL باستخدام PHP.
- عرض المشاركين.
- لوحة لاختيار فائز عشوائي.
- واجهة احترافية ومتجاوبة.

التقنيات:
PHP + MySQL + HTML + CSS + JavaScript

طريقة التشغيل على XAMPP:
1) فك الضغط عن المجلد وضعه داخل:
   C:\xampp\htdocs\

2) شغّل Apache و MySQL من XAMPP Control Panel.

3) افتح phpMyAdmin من:
   http://localhost/phpmyadmin/

4) اختر Import ثم اختر الملف:
   database.sql
   ثم اضغط Go.

5) افتح المشروع:
   http://localhost/Mohammed_Raffle_Project_v2/

الصفحات:
- index.php      الصفحة الرئيسية + التسجيل + المشاركون
- success.php    صفحة نجاح التسجيل
- select.php     لوحة السحب واختيار الفائز
- save.php       معالجة وحفظ التسجيل
- db.php         اتصال قاعدة البيانات
- config.php     اسم المشروع وموعد السحب

ملاحظة:
إذا كان MySQL عندك يستخدم كلمة مرور للـ root، عدّل $pass داخل db.php.
موعد العد التنازلي يمكن تغييره من config.php.
